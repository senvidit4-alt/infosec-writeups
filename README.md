# 🛡️ Cybersecurity & Bug Bounty Portfolio

Welcome to my central repository for security research, CTF write-ups, and vulnerability analysis. 

## 🎯 Objective
I created this repository to document my journey in ethical hacking, web exploitation, and bug bounty hunting. Rather than just finding flags, my focus is on deeply understanding underlying vulnerabilities, analyzing how they operate, and writing custom scripts and payloads to automate exploitation. 

Topics of particular interest include:
* Web Application Security (OWASP Top 10)
* Custom Exploit & Payload Scripting
* Data Privacy & Network Anonymity 

---

## 📂 Repository Structure
This repository is organized by platform and vulnerability category. Each folder contains a detailed write-up, including reconnaissance data, exploitation steps, custom code/scripts used, and mitigation strategies.

* `/PicoCTF` - Capture The Flag challenges focusing on applied concepts.
* `/PortSwigger` - Web Security Academy labs focusing on real-world bug bounty mechanics.
* `/HackTheBox` - Machine and application compromises (Retired machines only).
